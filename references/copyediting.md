# copyediting.md — 人工校对经验清单（防再犯规则）

> 来源：多轮「构建 → 人工目视 → 反馈 → 修复」闭环沉淀（空间灾害概论第 1 章 41 页，
> 4 轮人工检视反馈：示意图缺失 / 文字重叠 / 面板遮字 / 层叠倒置 / 伪符号标注 / 字号偏小）。
> 本清单是 Step 6 交付前的自查表；其中可数字化条款已进 verify / styleguide（各节标注）。

## ㈠ 图面构成：示意图优先，数据图兜底

人工反馈：课件「大部分是数据图，极少有示意图」；示意图是教学主线。

- 首选 **Office 形状示意**（graph / stack / shape / ladder 积木）：分层色带、
  同心圆嵌套、卡片矩阵、流程箭头——可编辑、文字自适应、与模板同字族。
  与铁律 7 同旨（"示意图首选 tikz / 组合 Office 形状，不 Python 制图"）。
- 其次 **tikz / 网络图**（注明出处）；确需量化曲线、剖面才用 Python 数据图落 image。
- **数据图更要查图内文字**：公式面板、轴标注、图例不得互相堆叠——面板优先
  放图面空区，xlim/ylim 放宽给面板让位；相邻标注数值要核对无交叠。
  matplotlib 脚本与 spec 同维护：改了脚本要重跑出图，核对嵌入字节
  （解包 media sha256 ↔ figs 源），防"改了源码却打包旧图"。
- 示意图满足"本页要讲清什么"：给"结构/关系/过程"的示意，不给装饰图。

## ㈡ 几何与文字位置：不重叠是底线，间隙是默认

人工反馈三连：① 附图文字重叠；② 公式面板遮字；③ 形状层叠顺序倒置。

1. **文字框与图形区：留 ≥0.2 英寸间隙**。文字框矩形右/下缘不得侵入相邻
   图形元素矩形（即使文字实际未满框——PowerPoint 按框排版，框相交就可能遮字）。
   经验公式：文字框缘 + 0.2 ≤ 图形缘。verify 遮挡断言只拦「相交未声明」，
   不拦「框相交但面积小/文字未满框」，故规范上要求显式分隔。
2. **有意的叠放必须显式声明**：`relations.overlap`（或同容器归属）。
   交叠语义 = 声明「谁压谁」：z 大者后绘制、视觉在顶层（铁律 2：spTree
   文档序越后越前）。未声明遮挡 = 违规，连图例盖在图上也要 overlap。
3. **堆叠层次全部在 spec 表达**：元素级 `z` 字段（优先级
   z_override > 元素 z > 声明序；ir_builder `alloc` 冲突顺延）。
   同心圆 / 瓦片式嵌套示意：外 → 内 z 递增（内层最后绘制、最上）；
   信息卡与图形区不重叠时无所谓穿插，只求各区域各自合理。
4. **改布局 = 改 SPEC 重跑**（铁律 1）；绝不手改产出 pptx/XML。
   `out_A3/base.pptx` 被 PowerPoint 打开会锁文件（Permission denied）——
   换输出目录或请用户关闭后再构建。

## ㈢ 字号分层（deck / 课件）——契约：verify S1b + styleguide body ≥16

人工反馈：正文 13–14 不显大气、后排不可读（"非标题内容除小字最好 16–18"）。

| 角色 | 规范 | 示例 |
|---|---|---|
| 标题 | 24–48 | 页眉、章节标题 |
| 正文（段落/卡片/要点条/小结·思考题） | **≥16（16–18 佳）** | 说明段落、信息卡、底部要点条 |
| 定义框（空间环境/空间天气/等离子体…） | 17 | 全宽定义带 |
| 表格 header / body | 14 / 13 | 数据表（格子宽度约束，不硬上 16） |
| 小字（豁免） | 任意小 | 图形标签 lab、图注 caption/note/units/foot/hdr/ftr、封面 meta、graph 节点 |

- verify S1b 强制：无 owner 的独立 text / shape（正文/卡片）fs ≥ body[0]=16；
  id 含小字豁免词（lab/caption/note/units/foot/hdr/ftr/meta）跳过；
  graph 节点 / cylinder 部件（有 owner）走各自通道不经此。
- **例外通道（作者降准）**：`meta.params.style.body_fs_min: <pt>` 显式覆盖正文下限
  ——仅用于"功能演示/密集表格"这类有意用小字的页（如 examples/closure 目录页提示）；
  正文排版页不得用（降准 = 明知违反 16pt 契约并留痕，report 里 fs/规范值照实写出）。
- 升级字号后**必须重跑 build**：字号 ↑ → 行数/行高 ↑ → 框高不够由 T 家族
  溢出断言拦（逐页调 rect 或精简文字）；表格格溢出则回退字号或加高 rect。
- 批量升级建议脚本化（CRLF 安全、按 id 白名单规则、幂等）；改完抽查实际
  渲染字号（XML `a:rPr sz` 属性，非 spec 声明的 fs），防 autofit 悄悄缩回。

## ㈣ 公式与符号标注三档规范

人工反馈两连：① 共振条件 ω−kv∥≈nΩ 不是 OMML 而是 Unicode；② C_D 这类
伪符号标注不要出现（"不便插 OMML 真公式就插入位置上的 Unicode 假公式"）。

1. **独立成块的公式 → `type: formula`**：expr 走 UnicodeMath 子集直接注入
   OMML（mc:AlternateContent Choice 分支，2016+ 渲染真数学公式，结构见
   formula-omml.md）；子集外不以陷落——`--com` 时 Word 批量引擎 BuildUp
   兜底注入（日志 `formula xxx: OK 引擎注入`）。公式排中央可加 overlap 声明。
2. **行内/图注/表格里的符号标注 → 禁止 ASCII 下划线伪符号**（C_D、ω_p、
   R_E 这类 `X_Y` 字面量）。三档替换：
   - 能 Unicode 下标化 → **Unicode 假公式**：ωₚ、Nₑ、Tᵢ、σₚ、σₕ…
     （可用字符表见 formula-omml.md §附；只含部分拉丁小写与数字、希腊字母；
     罗马大写 C/D/E/B/w 等无对应下标）；
   - 不能 Unicode 化的（C_D 的 D、R_E 的 E、λ_D 的 D）→ **文字化**：
     "阻力系数 / 地球半径 / 德拜尺度"；
   - 本就是整式（F_D = ½ρv²C_D A 这类）→ 归第 1 档公式元素。
3. **公式元素的 Fallback 是公式本身的 Unicode 兜底**（老 Office 降级分支），
   不算伪符号违规——清扫验证只看正文/卡片/表格/图注 XML 的 `a:t` 文本，
   跳过 formula 的 mc:Fallback 与 m:t（那里允许有 C_D 下标写法）。
4. 讲者备注（notes）是隐藏文本：行文符号一并 Unicode 化；完整备忘公式保留。

## ㈤ 校验与交付闭环（Step 6 自查）

1. `--com` 产 preview.png；把 base.pptx / preview.png 交用户目视，agent 不读图。
2. 目视反馈回来 = 改 SPEC 重跑，逐条对照本清单消除**同类**问题后再交；
   同一批反馈常命中同一类（如"符号标注"往往多处残留——全量扫再改）。
3. 物证：解包核验关键页（XML 断言 + media sha256 比对源图）；report.md 0 FAIL
   且 exit 0；动效/公式的 com_out 记录注入 OK。
4. 交付时说明：动效需 Office 播放复核、外部资源出处、公式双分支行为
   （2016+ 渲染 OMML，老版降级 Unicode）。

## ㈥ scansci 内化经验（连接/分组/排版规则三块，2026-09-30 落地）

> 来源：调研 Rimagination/scansci-svg（科研示意图引擎），内化「office 图形组合 +
> 文字排版」中可迁移的三条经验；SVG 制作/验证本身不入本 skill。

1. **连接位精确可控（具名锚点）**：默认磁吸锚点只保证「贴端口」，贴哪个端口
   由几何判据定——要表达"泵的出口接反应器的进口"这类语义连接位，用
   `anchors: {inlet: [0, 0.35], outlet: [1, 0.8]}`（归一坐标相对 rect）+ glue
   `from_anchor`/`to_anchor` 成对指定。规则：**锚点取名要含语义**（inlet/outlet/
   feed/tap），渲染/COM 绑定时披露锚点绝对位与站点中点偏差（>0.25in WARN）——
   连接位是图的内涵，不因磁吸几何兜底而丢失。
2. **编辑单元分组**：互遮的「玻璃/边框/高光」三件套类构图（必然叠加），若
   既非同容器又不想写 overlap 声明，用 `relations.edit_groups` 声明为一组——
   组内互遮合法（G4 第三源）、COM 一键 Group、z 收拢成连续区间。规则：成员
   必须顶层产生形状、一个元素只属一组；**Design 时把"哪些元素是一个编辑
   单元"与"哪些只是碰巧遮挡"分开判断**（scansci「三种组织分开判断」）。
3. **排版按规则而非逐元素**：引擎按规则（size_fs_floor 小尺寸字号下限 /
   labels_follow 标签须随目标）批量约束，而不是逐个手调字号/位置。规则：
   新页面风格先问「这条能写成作用于整页的规则吗」——能则进 styleguides
   可选键（缺省关闭零行为变化），不能才逐元素改；规则违规归 advisory
   （人工/LLM 裁定），不是机械自动修。
